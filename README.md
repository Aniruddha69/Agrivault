## ECSC Technology

### What is ECSC?

ECSC (Evaporative Cooling Storage Chamber) is a **low-cost, passive cold storage technology** that uses water evaporation to cool produce.

### How It Works

1. **Double-wall brick structure** filled with wet sand
2. **Water evaporates** from sand, absorbing heat
3. **Temperature drops** 5-11°C below ambient
4. **Humidity maintained** at 90-97% RH
5. **Produce stays fresh** 4-5× longer
