## ECSC Technology

### What is ECSC?

ECSC (Evaporative Cooling Storage Chamber) is a **low-cost, passive cold storage technology** that uses water evaporation to cool produce **without electricity**.

### How It Works

1. **Double-wall brick structure** filled with wet sand
2. **Water evaporates** from sand, absorbing heat
3. **Temperature drops** 5-11°C below ambient
4. **Humidity maintained** at 90-97% RH
5. **Produce stays fresh** 4-5× longer

### Chamber Specifications

| Parameter | Value |
|---|---|
| **Internal Size** | 2.0m × 1.5m × 1.5m |
| **Storage Volume** | 4.5 m³ |
| **Floor Area** | 3.0 m² |
| **Capacity** | 1,000 kg (1 ton) |
| **Temperature Achieved** | 5-11°C below ambient |
| **Humidity Maintained** | 90-97% RH |
| **Best Climate** | Hot & dry (RH < 40%) |
| **Shelf Life Extension** | 4-5× longer |
| **Water Requirement** | 2-3 times daily |
| **Lifespan** | 7-10 years |

### Construction Materials

| Material | Quantity | Purpose |
|---|---|---|
| **Bricks** | 600-800 nos | Double-wall structure |
| **River Sand** | 1.5 ton | Water retention for evaporation |
