## CHECKPOINT 1

### True or False

**Q:** Devices, such as TV or AC termed smart are AI-enabled. Is this statement true? Justify your answer.

**Answer:** False. Systems operating on fixed rules, predefined algorithms, and predetermined processes without the ability to learn, adapt, or make decisions beyond their programming are not considered Artificial Intelligence. Merely "smart" devices are forms of automation, whereas AI requires the ability to learn and adapt from experience.

### C. Short Answer Questions (20–30 words each)

**Q1: Explain the term machine learning.**
Machine learning is a branch of AI that enables computers to learn from data to make predictions or decisions without being explicitly programmed.

**Q2: Define supervised learning.**
Supervised learning is an ML approach where an algorithm learns from labelled data—where every example has a known answer—to predict outputs for new data.

**Q3: Define unsupervised learning.**
Unsupervised learning trains an AI system using unlabelled data to autonomously identify hidden patterns, structures, and relationships without prior knowledge.

**Q4: Name the approaches of supervised and unsupervised learning.**
The approaches for supervised learning are **classification** and **regression**. The approaches for unsupervised learning are **clustering** and **association**.

**Q5: Differentiate between regression and classification approaches of supervised learning.**
Regression predicts continuous numerical values, whereas classification maps inputs to discrete categories or classes.

**Q6: List two applications of ANN.**
Applications of Artificial Neural Networks (ANN) include **medical diagnosis** (identifying disease patterns) and **fraud detection** (analysing credit card transactions).

**Q7: Differentiate between classification and regression.**
Classification groups data into distinct categories, whereas regression estimates continuous numerical quantities based on mathematical relationships.

**Q8: What term is used to refer to machines that perform tasks with vast amounts of data using neural networks?**
The correct term is **Deep Learning (DL)**.

**Q9: List the applications of supervised learning.**
Supervised learning applications include image classification, weather forecasting, customer retention, market forecasting, and identity fraud detection.

**Q10: List the applications of unsupervised learning.**
Unsupervised learning applications include network anomaly detection, market basket analysis (association), and customer or book-store segmentation (clustering).

**Q11: Differentiate between supervised and unsupervised learning approaches.**
Supervised learning relies on labelled datasets to map inputs to correct answers. Unsupervised learning uses unlabelled datasets to discover hidden groupings or patterns.

**Q12: Differentiate between classification and regression.**

### D. Long Answer Questions (50–80 words each)

**Q1: What is regression in machine learning?**
Regression is a supervised machine learning technique that works on continuous data to predict numerical values. It aims to discover a mathematical relationship between independent input variables and a dependent output variable. Common applications include forecasting house prices based on location and size, predicting tomorrow's temperature, or estimating annual income.

**Q2: Describe classification in machine learning with an example.**
Classification is a supervised AI model that categorises data into distinct classes based on learned features. It trains on a labelled dataset to understand the relationship between inputs and output classes. For example, an email spam filter trains on messages labelled "Spam" or "Not Spam," learning to identify suspicious links or formatting to correctly classify incoming emails.

**Q3: What is clustering in machine learning?**
Clustering is an unsupervised machine learning approach that groups similar data points based on their characteristics. Because it uses unlabelled data, the algorithm identifies natural groupings without prior knowledge. Businesses commonly use clustering for customer segmentation in marketing, or for organizing unstructured data like grouping similar book titles by reader behaviour.

**Q4: Differentiate between supervised and unsupervised learning.**
Supervised learning trains models using labelled data, meaning every input comes with a known answer, allowing the model to classify or predict outcomes. Unsupervised learning uses unlabelled data, meaning inputs have no attached categories. Instead, the model searches for underlying similarities to organise data into clusters or discover hidden associations.

**Q5: Explain neural networks in the context of AI.**
Artificial Neural Networks (ANNs) are machine learning models inspired by the human brain. They consist of interconnected nodes (neurons) arranged in three main types of layers: an input layer, hidden layer(s) for computation, and an output layer for final decisions. During training, they adjust the weights of connections to minimise errors, making them effective for unstructured data analysis.

**Q6: How is deep learning different from neural networks?**
Deep learning is a specialized subset of machine learning that relies on deep neural networks. The term "deep" refers to the depth of the layers; while a basic neural network might have only two or three layers, deep learning algorithms utilise multiple hidden layers. This depth allows deep learning models to automatically extract features from complex raw data like images and audio.

**Q7: Differentiate between classification and regression.**
Classification and regression are both supervised learning algorithms. Classification categorises inputs into distinct, discrete classes, such as determining if a road sign says "Stop" or "Speed Limit." Regression predicts a continuous numerical value, such as estimating the resale price of a used car based on its mileage and age.

**Q8: What are the stages of the AI project cycle?**
After scoping the problem, the remaining stages include: **data collection/exploration**, **modelling**, **evaluation/testing**, and **deployment**. The modelling stage involves selecting the appropriate AI approach—such as supervised or unsupervised learning—and implementing algorithms to train the system around the data.

**Q9: Explain how neural networks work and mention three features.**
Neural networks process data through interconnected layers of neurons: an input layer receives signals, hidden layers perform computations using weights and activation functions, and an output layer provides the final decision. Three key features are: 1) they learn by adjusting connections (weights) during training; 2) they use backpropagation to correct errors; 3) they can automatically extract useful features from raw data.

**Q10: Convert the WFH scenario to a perceptron.**
For a work-from-home perceptron, we define four inputs: $x_1$ (remote performance is good), $x_2$ (no mandatory meetings), $x_3$ (company policy supports it), and $x_4$ (mutually beneficial). Each input is assigned a weight ($w$) indicating its priority, alongside a base bias ($b$). The perceptron calculates the weighted sum: $s = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + b$. It applies an activation function, outputting "Yes" if $s \ge 0$, and "No" otherwise.

## DEEP THINKING

**Q1: A bank wants to detect fraudulent transactions in real-time. Which type of ML would be suitable?**
**Supervised Learning (Classification)** is most commonly used, as it can be trained on past transaction records explicitly labelled as "genuine" or "fraudulent." **Unsupervised Learning (Anomaly Detection)** could also be applied to flag unusual deviations from baseline spending habits without prior labels.

---

**Q2: A social media platform wants to group users into segments based on interests. Which type of ML is most suitable?**
**Unsupervised Learning (Clustering)** would be most suitable, as it groups unlabelled data points (users) based on similarities in their characteristics or behaviours without needing predefined categories.

---

**Q3: How can PCA be used for image compression?**
Unsupervised learning techniques like dimensionality reduction simplify data by isolating the most critical features and patterns. This allows image data to be compressed by discarding redundant pixels while keeping essential structural elements intact.
